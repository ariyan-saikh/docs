## Top questions

<AccordionGroup>
  <Accordion title="What is the API base URL?">
    All requests go to `https://api.unpay.co/api/public/v1`. See the
    [API overview](/api-reference/overview).
  </Accordion>
  <Accordion title="How do I authenticate?">
    Send your secret key as `Authorization: Bearer agl_…` or in the `x-api-key`
    header. See [Authentication](/api-reference/authentication).
  </Accordion>
  <Accordion title="I lost my API key — can I recover it?">
    No. Secret keys are stored only as a hash and shown once at creation. Create
    a new key (or rotate the existing one) in **Developers → API Keys**.
  </Accordion>
  <Accordion title="How do I stop duplicate payouts?">
    Always send an `Idempotency-Key`. A retry with the same key returns the
    original payout instead of creating a new one. See
    [Idempotency](/api-reference/idempotency).
  </Accordion>
  <Accordion title="How do I get real-time updates?">
    Subscribe to [webhooks](/guides/verify-webhooks) for payout, call and
    campaign events instead of polling.
  </Accordion>
</AccordionGroup>
