## Which transfer modes are supported?

`imps`, `neft`, `rtgs` and `upi`. The available modes depend on your account —
`GET /payouts/accounts` shows per-mode availability. A disabled mode returns
`403 MODE_NOT_ENABLED`.

## Why does my payout fail with `INSUFFICIENT_BALANCE`?

A payout debits **amount + fee + GST**. Check `available` with
`GET /payouts/accounts/{accountId}/balance` before sending, and remember fees are
added on top of the transfer amount.

## Why is an `Idempotency-Key` required?

Money movement must be safe to retry. Every `POST /payouts` (and
`POST /payouts/bulk`) needs an `Idempotency-Key` (8–120 chars). A retry with the
same key returns the original payout instead of paying twice. Missing it returns
`400 IDEMPOTENCY_KEY_REQUIRED`. See [Idempotency](/api-reference/idempotency).

## What does `409 DUPLICATE_PAYOUT` mean?

You reused an idempotency key with a **different** request body. Use a fresh key
for each distinct payout; reuse the same key only when retrying the exact same
payout.

## What are the payout statuses?

```
queued → processing → completed
                    ↘ failed / returned
queued → cancelled
```

- `queued` — accepted, not yet sent (can be cancelled).
- `processing` — submitted to the bank/network.
- `completed` — funds delivered.
- `failed` / `returned` — terminal failure (e.g. wrong account, bank reject).
- `cancelled` — you cancelled it while still `queued`.

## Can I cancel a payout?

Only while it's `queued`, via `POST /payouts/{id}/cancel`. Once `processing`,
it can't be cancelled (`409 PAYOUT_NOT_CANCELLABLE`).

## What's the correct IFSC / account format?

- **IFSC** — 11 chars, RBI format `^[A-Za-z]{4}0[A-Za-z0-9]{6}$` (e.g. `HDFC0000123`).
- **Account number** — 4–34 alphanumeric characters.
- **UPI** — a valid VPA like `name@bank` (use `mode: upi`, `accountType: upi`).

## How many payouts can I send at once?

Up to **500** per `POST /payouts/bulk` call, under one batch idempotency key.
Per-item failures don't abort the batch — a `207` means some items failed, so
inspect each result. Look up a batch later with `GET /payouts/bulk/{batchId}`.

## Where do I check my account balance?

Use `GET /payouts/accounts/{accountId}/balance` (no default provider — pass the
account id), and size transfers against `available` (not `balance`) since fees
and holds apply. Accounts, statements and Connected Banking live balances are
covered in [Banking](/kb/banking).

## How do I track payouts without polling?

Subscribe to a [webhook](/guides/verify-webhooks) for `payout.completed`,
`payout.failed` and `payout.reversed`.
