Every payout draws from an **account**. This guide covers listing accounts,
checking a balance, understanding account types, pulling a statement, and
reading a live bank balance through Connected Banking. All endpoints need an API
key with the `payouts:read` [scope](/api-reference/scopes).

## List your accounts

```bash
curl https://api.unpay.co/v1/payouts/accounts \
  -H "Authorization: Bearer agl_your_secret_key"
```

Each account reports per-mode availability (IMPS/NEFT/RTGS/UPI) and a
`balanceSource`:

| `balanceSource` | Meaning |
|---|---|
| `ledger` | Balance is tracked in UnPay's ledger — authoritative. |
| `bank` | A Connected Banking account — the ledger figure is **not** authoritative; the balance endpoint fetches the live bank figure automatically. |

Note the `id` of the account you want to work with — it's the `accountId` used
below.

## Check an account balance

There is **one** balance endpoint for every account type, with **no default
provider** — you always pass the `accountId`:

```bash
curl https://api.unpay.co/v1/payouts/accounts/acc_123/balance \
  -H "Authorization: Bearer agl_your_secret_key"
```

The provider (and therefore the balance source) is resolved from the account:

- **Internal ledger account** → returns the ledger balance (`balanceSource: "ledger"`).

  ```json
  {
    "data": {
      "accountId": "acc_123",
      "accountNumber": "XXXXXX6789",
      "currency": "INR",
      "balanceSource": "ledger",
      "available": 152340.50,
      "balance": 152340.50,
      "holdBalance": 2500.00,
      "totalAvailable": 152340.50,
      "provider": { "id": "prv_1", "name": "unpay_wallet", "category": "wallet" }
    }
  }
  ```

- **Connected Banking account** → returns the **live** `clearBalance` from the
  partner bank in real time (`balanceSource: "bank"`).

  ```json
  {
    "data": {
      "accountId": "acc_456",
      "accountNumber": "XXXXXX6789",
      "currency": "INR",
      "balanceSource": "bank",
      "available": 875000.00,
      "clearBalance": 875000.00,
      "balFetchTimeStamp": "2026-07-09T10:15:00.000Z",
      "provider": { "id": "prv_2", "name": "yes_bank", "category": "bank_account" }
    }
  }
  ```

Always size transfers against `available` (the canonical spendable figure). A
payout debits **amount + fee + GST**, and in-flight payouts are reserved as
`holdBalance`, so leave headroom for both.

Common errors: `400 ACCOUNT_ID_REQUIRED`, `404 ACCOUNT_NOT_FOUND`,
`409 PROVIDER_NOT_FOUND` / `PROVIDER_INACTIVE`, `400 NO_LINKED_ACCOUNT` /
`UNSUPPORTED_RAIL` (Connected Banking not usable), or `502 BANK_UPSTREAM_ERROR`
(the partner bank API was unavailable — retry with backoff).

## Pull a statement

Get a paginated ledger of account transactions, with optional filters:

```bash
curl "https://api.unpay.co/v1/payouts/statement?dateFrom=2026-07-01&dateTo=2026-07-09&page=1&pageSize=50" \
  -H "Authorization: Bearer agl_your_secret_key"
```

Filter by `dateFrom`, `dateTo`, `type` and `walletId` (the account id). Page with
`page` and `pageSize` (max 200).
