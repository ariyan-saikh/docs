The UnPay Public API is a REST, JSON, server-to-server API. Every request is
authenticated with an API key scoped to your account, and every response is
tenant-isolated to the key owner.

<Note>
  **Base URL**

  ```
  https://api.unpay.co/api/public/v1
  ```
</Note>

## Conventions

- **Requests** are JSON (`Content-Type: application/json`).
- **List responses** return `{ "data": [...], "total": n }`.
- **Errors** return `{ "error": "message", "code": "MACHINE_CODE" }` — see [Errors](/api-reference/errors).
- **Money** is expressed in major units (₹) with up to two decimal places.
- **Timestamps** are ISO-8601 (UTC).

## Core concepts

| Concept | Summary |
|---|---|
| [Authentication](/api-reference/authentication) | `Authorization: Bearer agl_…` or the `x-api-key` header. |
| [Scopes](/api-reference/scopes) | Each key grants a fixed set of read/write scopes per resource. |
| [Idempotency](/api-reference/idempotency) | Required for money movement — retries never double-pay. |
| [Rate limits](/api-reference/rate-limits) | Per-key request budget; `429` when exceeded. |
| [Request signing](/api-reference/request-signing) | Optional HMAC signing for high-assurance keys. |

## Get an API key

Create and scope keys in the [UnPay Dashboard](https://app.unpay.in) under
**Developers → API Keys**. Grant only the scopes an integration needs, and
optionally restrict a key to specific IPs or require signed requests.

<Warning>
  Your secret key (`agl_…`) is shown once at creation and stored only as a hash.
  Keep it server-side — never ship it in browser, mobile, or public code.
</Warning>
