This guide takes you from zero to your first successful API call.

<Steps>
<Step title="Create an API key">
  Sign in to the [UnPay Dashboard](https://app.unpay.in) and go to
  **Developers → API Keys**. Create a key, grant it the scopes you need
  (for example `payouts:read` or `agents:read` to start), and copy the secret.

  <Warning>
    The secret (`agl_…`) is shown **once**. Store it in your secrets manager —
    it can't be retrieved later, only rotated.
  </Warning>
</Step>

<Step title="Verify the key">
  Call `GET /me` to confirm the key works and see the account it belongs to.

  ```bash
  curl https://api.unpay.co/v1/me \
    -H "Authorization: Bearer agl_your_secret_key"
  ```

  ```json
  {
    "id": "usr_...",
    "email": "you@company.com",
    "name": "Acme Payments",
    "credits": 12500,
    "planType": "growth"
  }
  ```
</Step>

<Step title="Make your first product call">
  Pick the product you're integrating.

  <Tabs>
    <Tab title="Payouts">
      List your accounts (needs `payouts:read`):

      ```bash
      curl https://api.unpay.co/v1/payouts/accounts \
        -H "Authorization: Bearer agl_your_secret_key"
      ```

      When you're ready to send money, see the
      [first payout guide](/guides/first-payout).
    </Tab>
    <Tab title="AI Calling">
      List your voice agents (needs `agents:read`):

      ```bash
      curl https://api.unpay.co/v1/agents \
        -H "Authorization: Bearer agl_your_secret_key"
      ```

      To launch a campaign end-to-end, see the
      [first campaign guide](/guides/first-campaign).
    </Tab>
  </Tabs>
</Step>

<Step title="Subscribe to events">
  Create a webhook so UnPay pushes payout, call and campaign updates to your
  server in real time — see [Verifying webhooks](/guides/verify-webhooks).
</Step>
</Steps>
